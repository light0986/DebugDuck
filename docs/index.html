DebugDuck 🐤 網頁版

把你的 bug 一行一行講給鴨子聽。

小黃鴨除錯法是什麼？

對著桌上的橡皮鴨，一行一行把程式碼講給牠聽、解釋每一步「應該」做什麼。 因為「把問題講清楚」會強迫大腦換個角度重走一遍邏輯，常常講到一半，自己就發現 bug 在哪了。

這裡的鴨子只會「嘎」—— 牠不會幫你解 bug，重點是你講出來的過程。

怎麼玩

  • 拖曳小鴨 —— 換位置（會記住，重新整理也在原位）
  • 左鍵點一下小鴨 —— 牠會 Q 彈壓扁一下 + 叫一聲
  • 對小鴨按右鍵（手機長按）—— 開選單：跟鴨子說話 / 查看歷史訊息 / 回到畫面中央 / 關於
  • 跟鴨子說話 —— 打字送出，牠思考 3 秒後隨機回你一句（嘎 / 嘎嘎 / 嘎嘎嘎 / ? / !）
  • 你送出的每一句都會存進歷史訊息（以時間戳記斷句），鴨子的回應不記錄
